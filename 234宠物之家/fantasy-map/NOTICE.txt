This site integrates the native editable .map serializer and loader with its
account service, including workspace preferences, custom assets and native save slots.
The editor is a static browser build. To reproduce it, check out v1.158.0,
apply upstream.patch, place editor/fonts into public/fonts, install pinned
dependencies with npm ci, then run npx vite build --mode electron --base ./.
Copy dist-electron/renderer into editor/. Electron mode here produces relative
asset URLs and excludes analytics. The application runs in a normal web browser.
