# 小说阅读 1.0

2026-11-14。现有 GitHub Pages 游戏页面的独立功能卡片，入口 `games.html` → `reader/`。无构建步骤、外部运行库或后端变更，不嵌入钓鱼界面。

## 阅读功能

- 站内书架四部古典小说，共816章。字号14–30px、日间/夜间、目录跳转、前后页、跨章前后翻页及全屏阅读。
- 自动翻页可选5/10/20/30/60秒。展开目录、返回书架、切后台、加载失败和读到末页时停止；返回页面不会偷偷补翻错过的页数。
- 按实际DOM排版高度拆页；保存章节与字符偏移，字体或视口改变后回到覆盖原位置的一页。每章各页字符串联等于全文，没有凭估算截断内容。
- `pet234:reader:v1` 在本机localStorage保存字号、模式、间隔与各书阅读位置。存储禁用/损坏时仍可读，界面明确不保证保存。没有新增云存档模块。
- 桌面方向键/PageUp/PageDown翻页。手机纵向、横向均可读，不强制旋转；全屏API不支持时保留铺满页面的阅读布局。

## 网文来源

`web-sources.json` 收录8个核验过的官方平台入口与3个GitHub书源项目。平台按钮明确打开原站，原站的登录、付费及阅读设置由该站提供。GitHub项目展示其用途和配套服务要求；本站不把它们宣称为已经可直读的正文接口，也不执行第三方规则中的脚本。外链新窗口使用noopener/noreferrer，全部为HTTPS。

古典原文的来源、许可、制作人署名及完整性校验见 [SOURCES.md](SOURCES.md)。完整电子版来源声明在各书的source-notice.txt，并可从章节目录打开。

## 性能与验证

目录约65KB，打开书后仅请求当前章节（最大约28KB），正文内存缓存最多3章；每次翻页只更新当前页文本。书库原文虽约7MB，不会在进入书架时全量下载。分页计算每3页让出一帧，避免长时间阻塞手机操作。

浏览器验证覆盖：游戏页面入口、4书首尾章、全文分页无缺字重复、跨章往返、目录跳转、进度重载、夜间和字号持久化、14–30px边界、自动5秒/跨章/末页停止、目录/后台/关书暂停、全屏、网络失败重试、损坏或禁用存储、实际3章缓存淘汰。视口390×844、844×390和320×568无裁切或横向溢出。8个网文入口和3个GitHub外链及独立加载失败重试亦通过。

桌面Chrome模拟390×844手机、CPU降速4倍时，首次章节加载与排版约1.42秒，JS堆约2.2MiB；这不等同实体手机测试。古典正文逐章用textContent显示，不解析正文HTML。
