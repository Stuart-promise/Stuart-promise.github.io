# 小说阅读 1.5

从游戏页面打开 `reader/`。阅读器沿用 GitHub Pages 静态页面，本机书架、阅读进度和古典书库与之前版本兼容。

## 搜索、目录与书架（2026-11-23）

- “全部书源”和单源检索支持书名、作者。读者可从结果进入目录、阅读正文或加入书架。相同书名的不同来源分别保存。
- 番茄小说（社区书源）、开心文学网、错层小说和笔趣阁7均通过站内阅读器打开。番茄按关键词实时查询；公开章节若指定正文字体，浏览器载入对应字体后再排版。
- 已下架的官方书源不再参与搜索。原书架中的收藏和章节记录继续保存在本机；点击“换源找书”可按原书名在现有书源中选择其他版本。各版本有独立目录和进度。
- 来源列表由后台动态提供。单源故障会显示来源提示，仍可使用已返回的其他结果；所有来源均未返回时也会提示故障。搜索页最多接收 120 项，总结果最多 300 项。
- 书架最多 100 本，存于本机 `pet234:reader:shelf:v1`。设置及最近 140 本阅读进度存于 `pet234:reader:v1`。移出书架保留进度。站内正文按章节与字符位置续读。古典书库 4 本共 816 章，独立于外部书源。

## 翻页模式

阅读设置可选择“左右仿真翻页”或“上下滑动”，选择保存在原设置中。左右模式支持按钮、键盘与左右滑动，手动使用纸页翻动效果；自动按5/10/20/30/60秒间隔，从上向下覆盖为下一页。上下模式使用当前章节的原生纵向滚动，自动滚动速度按所选秒数/屏计算；底部按钮按屏移动，章末再向上滑可进入下一章。自动到达章末后停留一个阅读间隔，再继续下一章，短章节也不会一闪而过。

滚动位置通过首个可见文字的字符偏移保存，切换模式、字号、屏幕尺寸和刷新后继续原位置。手动触摸/滚轮、目录、书架、后台或加载失败会暂停自动阅读；全书末尾停止。动画取消会清理临时图层，系统开启减少动态效果时缩短动画。

翻页动画只保留最多两层当前页面文字，不使用Canvas或图片快照；纵向滚动只有正在阅读时运行一个动画帧回调，低速滚动保留小数位以避免移动端停滞。正文仍为按章获取与最多3章缓存。

## 配套服务

`web-library.mjs`调用`https://111.228.4.20/v1/reader`。服务`pet234-reader`独立监听127.0.0.1:18105，Nginx转发`/v1/reader/`。原有账号、游戏存档及联机服务保持独立。

后端采用httpx和标准库解析器，自行适配具体网页结构，不执行GitHub书源中的JavaScript。固定HTTPS域名；数字编号或错层严格UUID；核对目录和章节归属。服务操作24秒超时，按IP限速，单个源响应最多3MiB。内存缓存最多12MiB/256项，共享目录索引最多8本；systemd限制192MiB内存。

错层目录每页500章，最多30页，额外目录页并发3，总目录限时22秒，任一页失败即取消剩余请求并提示重试。只获取正在阅读的正文，正文不完整时明确提示，不把残缺章节标成完整内容。

## 手机与历史验证（1.3 及更早版本）

浏览器正文缓存最多3章，每次翻页只更新当前页文本，分页计算每3页让出一帧。古典书库约7MB，进入书架只取约65KB目录，各章按需获取；网文也不会整本下载。手机横屏、竖屏均可读，全屏不支持时使用铺满页面布局。

65项服务测试覆盖3个社区源及旧来源、目录分页、ID/归属、受限章、编码、响应上限、缓存、CORS、限速与搜索排序。真实三源搜索→完整目录→正文通过；浏览器检查三源聚合精确匹配、目录选章、加入书架、刷新续读、字号/夜间/5秒自动翻页、390×844/844×390/320×568布局、旧书架兼容、无外跳和无页面异常。首章受限、全书受限及已有进度4种情况另有回归验证。

原有古典分页完整性、跨章往返、目录、存储损坏/禁用、网络重试及过期请求隔离测试保留。验证采用桌面Chrome手机尺寸模拟，不等同实体手机测试。

1.3模式回归：完整章节分页逐字一致，手势方向、纸页效果和向下覆盖、原生触摸滚动、自动滚动、章节前后衔接、短章节停留、模式/字号/视口/重载位置、减少动态效果、后台暂停、失败重试和末页停止均验证。另覆盖翻页中打开目录、自动覆盖中切换夜间模式和60秒/屏慢速滚动的中断处理。
