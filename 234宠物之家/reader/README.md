# 小说阅读 1.1

2026-11-14。现有 GitHub Pages 游戏页面的独立功能卡片，入口 `games.html` → `reader/`。网页无构建步骤和外部运行库；网文来源由独立只读服务提供，不嵌入钓鱼界面。

## 阅读功能

- 站内书架四部古典小说，共816章。字号14–30px、日间/夜间、目录跳转、前后页、跨章前后翻页及全屏阅读。
- 自动翻页可选5/10/20/30/60秒。展开目录、返回书架、切后台、加载失败和读到末页时停止；返回页面不会偷偷补翻错过的页数。
- 按实际DOM排版高度拆页；保存章节与字符偏移，字体或视口改变后回到覆盖原位置的一页。每章各页字符串连接后等于全文，没有凭估算截断内容。
- `pet234:reader:v1` 在本机localStorage保存字号、模式、间隔与各书阅读位置。存储禁用/损坏时仍可读，界面明确不保证保存。没有新增云存档模块。
- 桌面方向键/PageUp/PageDown翻页。手机纵向、横向均可读，不强制旋转；全屏API不支持时保留铺满页面的阅读布局。

## 网文搜索与站内阅读

1.1新增17K小说网与SF轻小说公开内容适配器。搜索书名或作者，可选单一书源或同时搜索；搜索结果可直接打开目录/阅读或加入书架。正文在本阅读器内显示，沿用字体、夜间模式与自动翻页。书架可加入/移除最多100本，保存在本机`pet234:reader:shelf:v1`；最近140本阅读进度按更新时间保留，网文使用`sourceId:bookId`隔离位置。移除书架不删除阅读进度。古典书库和原有设置保持兼容。

目录每次展示100项，可筛选和翻页；官方目录标为VIP的章节明确锁定，服务不会尝试抓取其正文。源站要求登录、购买或额外验证时在本页提示。纯插画/无文字章提供直接切换上一章、下一章或选择目录。网络故障可重试；自动翻页在这些情况下停止。未登录原平台的本服务只提供公开文字章节，不提供订阅或登录代办。

`web-library.mjs`调用`https://111.228.4.20/v1/reader`的sources、search、books与chapters接口。客户端超时30秒，取消过期搜索/旧书请求；返回内容经过格式与ID校验后以textContent呈现。1.0的外部平台跳转界面已退出主流程，旧`web-sources.*`数据文件只保留历史来源记录。

配套后端独立部署为`pet234-reader`，监听127.0.0.1:18105，Nginx只将`/v1/reader/`转发到此服务。原账号、存档及联机服务保持原进程。后端采用FastAPI/httpx/标准库解析器，固定HTTPS官方域名和数字书/章节编号，不接收任意URL，不执行远程书源脚本。按需获取当前搜索页/目录/章节，3MiB源响应上限，24秒操作时限，4个服务操作并发，按IP限速；服务内缓存最多12MiB/256项，目录索引最多8本。systemd限制192MiB内存，独立低权限账号与只读文件系统。

古典原文的来源、许可、制作人署名及完整性校验见 [SOURCES.md](SOURCES.md)。完整电子版来源声明可从古籍目录打开。网文目录标明内容来源，无需离开阅读页。

## 性能与验证

目录约65KB，打开书后仅请求当前章节（最大约28KB），正文内存缓存最多3章；每次翻页只更新当前页文本。书库原文虽约7MB，不会在进入书架时全量下载。分页计算每3页让出一帧，避免长时间阻塞手机操作。

浏览器验证覆盖：游戏页面入口、4书首尾章、全文分页无缺字重复、跨章往返、目录跳转、进度重载、夜间和字号持久化、14–30px边界、自动5秒/跨章/末页停止、目录/后台/关书暂停、全屏、网络失败重试、损坏或禁用存储、实际3章缓存淘汰。视口390×844、844×390和320×568无裁切或横向溢出。1.0的外链入口验证现作为历史记录保留，1.1已改为下述站内阅读验证。

桌面Chrome模拟390×844手机、CPU降速4倍时，首次章节加载与排版约1.42秒，JS堆约2.2MiB；这不等同实体手机测试。古典正文逐章用textContent显示，不解析正文HTML。


1.1验证：18项服务测试覆盖来源解析、目录归属、VIP拒绝、无文字章、HTTPS白名单/跳转限制、响应大小/验证页处理、来源局部失败、缓存、CORS和限速。真实两源搜索→目录→正文通过；浏览器覆盖加书架/重复添加/移除、选章、翻页/刷新位置、三种手机尺寸、字号/夜间/自动翻页、旧搜索/旧目录响应竞态、失败重试、目录分页/筛选、VIP与无文字章跳转及原有古典阅读回归。
