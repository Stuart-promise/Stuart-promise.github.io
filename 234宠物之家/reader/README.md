# 小说阅读 1.2

2026-11-14。现有GitHub Pages游戏页面的独立功能，入口`games.html` → `reader/`。网页无构建步骤和外部运行库，正文由独立只读服务按章节提供。

## 社区书源与书架

默认搜索启用3个GitHub社区书源：**开心文学网、错层小说、笔趣阁7**。出处、固定提交及实际验证见[SOURCES.md](SOURCES.md)。可搜索书名或作者，选择单源或同时搜索；精确书名、作者优先，同等相关结果按来源交错展示。搜索页最多接收120项，总结果最多300项；同名作品保留各自来源，加入书架时使用独立标识。

搜索、目录选择、正文阅读及加入书架均在本阅读器内完成。目录每组100项，支持名称/序号筛选；正文按实际DOM排版分页，支持14–30px字号、日间/夜间、5/10/20/30/60秒自动翻页、键盘翻页与全屏。展开目录、返回书架、切后台、加载失败和末页会停止自动翻页。

首次打开从首个可读章节开始，已有进度回到原位置。受限章节、无文字章节和网络故障在页内提示，支持选择其他章节或重试。原有平台适配器仅用于旧书架兼容，不出现在默认搜索选项中；古典书库4本816章继续保留。

书架最多100本，存于本机`pet234:reader:shelf:v1`。设置及最近140本阅读进度存于`pet234:reader:v1`，按章节与字符位置续读；改变字体或视口后仍回到原文位置。移出书架不删除进度。存储受限时仍可阅读并显示保存状态。书架没有新增云同步。

## 配套服务

`web-library.mjs`调用`https://111.228.4.20/v1/reader`。服务`pet234-reader`独立监听127.0.0.1:18105，Nginx转发`/v1/reader/`。原有账号、游戏存档及联机服务保持独立。

后端采用httpx和标准库解析器，自行适配具体网页结构，不执行GitHub书源中的JavaScript。固定HTTPS域名；数字编号或错层严格UUID；核对目录和章节归属。服务操作24秒超时、6并发、按IP限速，单个源响应最多3MiB。内存缓存最多12MiB/256项，共享目录索引最多8本；systemd限制192MiB内存。

错层目录每页500章，最多30页，额外目录页并发3，总目录限时22秒，任一页失败即取消剩余请求并提示重试。只获取正在阅读的正文，正文不完整时明确提示，不把残缺章节标成完整内容。

## 手机与验证

浏览器正文缓存最多3章，每次翻页只更新当前页文本，分页计算每3页让出一帧。古典书库约7MB，进入书架只取约65KB目录，各章按需获取；网文也不会整本下载。手机横屏、竖屏均可读，全屏不支持时使用铺满页面布局。

65项服务测试覆盖3个社区源及旧来源、目录分页、ID/归属、受限章、编码、响应上限、缓存、CORS、限速与搜索排序。真实三源搜索→完整目录→正文通过；浏览器检查三源聚合精确匹配、目录选章、加入书架、刷新续读、字号/夜间/5秒自动翻页、390×844/844×390/320×568布局、旧书架兼容、无外跳和无页面异常。首章受限、全书受限及已有进度4种情况另有回归验证。

原有古典分页完整性、跨章往返、目录、存储损坏/禁用、网络重试及过期请求隔离测试保留。验证采用桌面Chrome手机尺寸模拟，不等同实体手机测试。
