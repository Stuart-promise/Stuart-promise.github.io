# 金币大亨 1.1

网页版第一人称增量游戏。网页与素材发布在现有 GitHub Pages，账号存档复用234宠物之家的云存档API。

## 两张地图

第一图为固定20,880枚金币山，最高2.88米。初始每1.05秒拾取1枚、移速1.8米/秒、背包12枚，每枚回收1元。12项科技覆盖拾取、搬运、工具。金币全部拾取后停止补货，显示第二图入口；进入时自动结算最后一包金币，仅结算一次。

第二图「菌香小馆」有900朵蘑菇，采完一批后再生。采集→送到入口出餐口→待制队列→烤串出餐获得资金。每朵做一串，交付时不发钱，烤制完成才发钱；可以离开出餐口继续采摘，烤炉在游戏进行时运转，暂停/离线不计算收益。

两张图的科技完全独立。第一图科技保留记录，但不会影响第二图的采集量、间隔、距离、范围、移速、背包、卸货、工具、自动采集或售价。第二图初始每1.2秒采1朵、容量12朵、移速1.8米/秒、出餐0.5串/秒、每串12元。第二图有独立的12项研究，分采菇效率、烤串出餐、搬运工具三组。两图资金沿用同一余额；科技必须在所属地图购买。数值、价格和前置关系在model.mjs。

## 操作

电脑WASD/方向键移动，拖动视角或点击画面锁定鼠标，长按空格采集；E交付，T科技树，Esc暂停/返回。手机左摇杆移动，右侧滑动转向，长按采集按钮；工作台附近显示交付按钮。支持横屏、全屏及竖屏旋转坐标转换。失焦、切后台暂停。控制区域禁止文字选择、长按菜单，松手/取消后停止采集。

## 存档

沿用PetAccount.open('coin-tycoon')与pet234-coin-tycoon-v1存档键。schema3保存地图、金币山通关状态、资金、两张独立科技树的等级、各自采集记录、蘑菇批次、烤炉队列和烤制进度。金币与蘑菇分别压缩为位图，完整进度小于5KB。

兼容schema1/2，保留旧版资金、背包、科技和采集记录；旧版已累计采完一整座金币山并补货的存档可直接进入第二图。账号隔离、冲突暂停、云端版本历史、游客本机保存、Web Locks重复页面保护均沿用现有机制。拾取、购买、交付与地图切换即时本机保存，位置/烤制每5秒保存，离开时尝试同步。云端无需修改。

## 渲染

WebGL 2 / Three.js 0.187.0，本地vendor目录含MIT许可，无第三方CDN请求。场景、手部、工具、金币、蘑菇和烤炉由代码建模。金币山使用高度场，只显示外层金币；摄像机沿坡面移动。蘑菇菌柄、菌盖、斑点共用3组实例网格；采集和再生重用网格。切图释放旧场景几何体、材质、纹理与渲染器。

像素比上限1.5，游戏60FPS、菜单12FPS，后台停止绘制。无动态阴影、后处理、独立物理模拟。桌面Chrome模拟844×390视口、CPU降速4倍，蘑菇图约60FPS、14.6万三角形、83绘制调用；不等同实体低端手机实测。

## 验证

运行node --test model.test.mjs pile.test.mjs mushrooms.test.mjs，覆盖经济循环、科技前置、满级第一图与基础第二图能力完全隔离、禁止跨图购买、最后一枚金币通关、末包只结算一次、蘑菇队列分步出餐/价格升级、再生、旧存档迁移和两图紧凑存档还原。

浏览器实测最后金币采集→通关→切图，蘑菇采集→交付→远离烤炉后继续出餐，采集/出餐/售价三类升级，真实本地测试账号云存档往返和刷新恢复。横竖布局与长按采集无文字选区。
